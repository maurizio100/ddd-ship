# Fleet — glossary

Terms specific to this context. Shared terms and cross-context collisions are in
[`../../glossary.md`](../../glossary.md).

| Term | Definition | Notes |
|------|------------|-------|
| Available Ships | The list of all ships in the fleet, shown with their Catain and current shipping status. | UI heading on the ships list. |
| Catain Image | The portrait of a Catain, stored in object storage and referenced by an image id. | |
| Hire | The User taking one Recruit from the Harbor's Recruit Pool into a ship's Crew with one click. | Planned (crew ideation, 2026-10-05). Only at the ship's Home Harbor, only while its Shipping is being prepared, only while the Crew is below the ship's Crew Capacity, and only if the Harbor's Savings can pay the Hiring Fee (Trade); otherwise refused. Open: can a Crew Member be dismissed. |
| Recruit | A cat in a Harbor's Recruit Pool who can be Hired onto a ship. | Planned (crew ideation, 2026-10-05). Becomes a Crew Member once Hired. Open: do Recruits have traits; do they have an image. |
| Recruit Pool | The Recruits a Harbor offers for Hiring. | Planned (crew ideation, 2026-10-05). Each Harbor has its own pool, unlike the Catain roster, which is the same at every Harbor. Open: how a pool is filled (proposal: generated at the Harbor, so every Harbor's seeds stay identical). |
| Ship Class | The size of a ship, chosen when it is created, which sets its Crew Capacity: how many Crew Members it can carry. | Planned (crew ideation, 2026-10-05). Example values Sloop, Brig, Galleon; values and capacities open. Open: whether it also sets the Max Weight (CargoLoading), today 15.0 for every ship. |
| Ship Name | The name a ship is known by; mandatory, non-blank, shorter than 255 characters. | |

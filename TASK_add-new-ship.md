# Task: Add New Ship — Frontend Feature

## Goal

Add a page to the existing Angular frontend that allows users to create a new ship.
The backend API for creating ships is already implemented and available.

---

## Acceptance Criteria

- The user can navigate to a "Create Ship" page from the ships list
- The form requires a **ship name** and a **captain** — both are mandatory
- Submitting the form with valid data creates the ship
- After successful creation, the user is redirected back to the ships list
- The form cannot be submitted while either field is empty
- The user can cancel and return to the previous page without creating a ship
